# 本地无限画布 · xy-wxhb

把 ComfyUI 的工作流摆到一块无限画布上：**一个节点 = 一次生成**。素材、参数、LoRA、
模型都摊在节点里改，跑完的结果自动接到旁边，可以继续往下喂。

```
v1.1.1 · 源码公开 · 仅限非商业使用 · Windows / macOS / Linux
```

🎬 **演示视频（47 秒，无旁白）**：[`docs/xy-wxhb-demo.mp4`](docs/xy-wxhb-demo.mp4)
—— 工作流上画布 → 改参数自动写回 → 提示词连线 → 平移缩放框选 → 开跑与随时停止。
画面里的操作全部是真实操作，不是动画模拟。

为什么不用 ComfyUI 自带的面板：

- **零安装** —— 纯前端 + 一个只用 Python 标准库的脚本，不需要 npm，不需要 `pip install`
- **不改 ComfyUI** —— 只通过它自己的 HTTP 接口读写工作流和素材，装在哪个盘都能用
- **本地优先** —— 默认只听 `127.0.0.1`，不联网、不注册、不上传任何东西
- **面向长流程** —— 一条片子几十个镜头时，队列和节点图比一排标签页看得清

## 快速开始

**前提**：本机 ComfyUI 已经跑起来（默认 `http://127.0.0.1:8188`）。
画布只负责连它，不负责启动它。

### 方式一：下载绿色包（推荐，不用装任何东西）

1. 到 [Releases](../../releases) 下载 `xy-wxhb-v1.1.1.zip`，解压到任意目录
2. Windows 双击 **`start.bat`**；macOS / Linux 执行 **`./start.sh`**
3. 浏览器自动打开 `http://127.0.0.1:8277/`

启动脚本会自己找 Python，按这个顺序：`XY_WXHB_PYTHON` 环境变量 → 同目录的便携 Python →
**ComfyUI 整合包自带的 Python** → `py -3` → PATH 里的 `python` / `python3` → 扫一遍磁盘上的 `ComfyUI*/`。
所以只要你机器上跑着 ComfyUI，通常什么都不用配。

### 方式二：从源码跑

```bash
git clone <本仓库地址>
cd xy-wxhb
python serve.py          # 需要 Python 3.8+
```

### 系统要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11，macOS，Linux |
| Python | 3.8 以上（只用来起本地服务，不需要装第三方包） |
| 浏览器 | Chrome / Edge / Firefox 近两年的版本（用了 ES module、CSS 变量） |
| ComfyUI | 任意版本，能正常出图即可；素材库需要它的 `input` / `output` 目录可读 |

### 启动参数

```bash
python serve.py -p 9000        # 换端口（被占用时会自动往后找）
python serve.py --no-browser   # 不自动开浏览器
python serve.py --host 0.0.0.0 # 让局域网其它设备也能访问（默认只听本机）
python serve.py -v             # 看版本
```

> 为什么非要起个本地服务器？因为 ES module 在 `file://` 下会被浏览器拦掉。
> 这个服务只做两件事：发静态文件，以及代理「素材库」需要的列目录 / 删文件
> （ComfyUI 官方接口只给按文件名取文件，没有列目录）。

### 出问题了

| 现象 | 原因与处理 |
|---|---|
| 双击后窗口一闪就没 | 没找到 Python。命令行里跑 `start.bat` 能看到具体提示；或先 `set XY_WXHB_PYTHON=你的python.exe路径` 再启动 |
| 提示端口被占 | 会自动改用 8278、8279…，看控制台打印的地址即可；也可以 `-p` 指定 |
| 页面能开，但一直「未连接」 | ComfyUI 没开，或地址不对。在顶栏输入框改完点「连接」 |
| 素材库显示「未就绪」 | 没自动认出 ComfyUI 根目录。在素材库面板里手动选一次，之后会记住（存进 `comfy-root.txt`） |
| 改完代码没生效 | `serve.py` 要重启；前端刷新即可（静态资源是 `no-store`，不吃缓存） |

更细的用法、每块面板为什么这么设计，见下面正文。

## 怎么用

1. 左侧选一个工作流 → 点击，画布上出现一个节点
2. 节点自上而下分四段：**① 素材 ② 参数设置 ③ LoRA ④ 模型选择**，改提示词 / 尺寸 / 步数 / 模型都在这里
3. 点节点右上角 **▶** 运行
4. 跑完的结果**不在节点里**，而是自动接到右侧一个**内容节点**（提示词 / 图片 / 视频 / 音频）上，
   点图可看大图，内容节点还能继续当上游喂给别的节点

### 工作流节点的四段

| 段 | 装什么 | 说明 |
|---|---|---|
| **① 素材** | 图 / 视频 / 音频文件字段（`LoadImage.image`、`LoadVideo.file`、`LoadAudio.audio`…） | **图框在上、按钮在下、同类型横排**：一格一个文件，角标写清是哪个口（参考图 3 / `LoadImage` / `I2VA first frame`），格子里是下拉 + **「上传」**（选本机文件直接传进 ComfyUI 的 `input/` 并选用）；autogrow 参考槽与「首帧 / 遮罩」这类固定口用同一套方块卡，固定口单独列在「其他素材」下。缺文件时卡片变红 |
| **② 参数设置** | 提示词、画幅 / 时长 / 分段模式、尺寸、采样、其余零散参数 | 提示词直接展开；**画幅比例、分段模式、时长（`duration` / 帧数）紧跟提示词单独一排**（`aspect_ratio` 排最前，导演台的 `task_type` 紧随其后）——这三格是「先定框架」的参数：模式决定这条流吃哪种素材，画幅和时长决定宽高帧数步数；尺寸/采样**连着排成两列**（同一道次一张网，节点名降级成标签右侧的 `#2 节点名` 角标），多道真采样按 **一采 / 二采 / 三采** 分块；**批量张数、重绘幅度**和其它零碎项折在「更多参数」里；**ComfyUI 里点不到的参数**收在最底部只读块。**时长藏在常量节点里的流也能改**：转换时把被内联掉的常量（`PrimitiveFloat` 标题写着 `Float (duration)`）和「由表达式算出的帧数」一起翻出来 —— 面板上就有「时长（秒）」一格，改它帧数自动重算 |
| **③ LoRA** | 每个 `LoraLoader*` 一张卡 | **模型名在上面、它自己的强度紧贴在下面**，谁配谁一眼看清；一采二采各挂一套时卡头写清是哪一道；每张卡带 **「不启用 / 启用」**（跟素材同一套语义：停用的不提交，同时把 ComfyUI 那边这个节点设成旁路） |
| **④ 模型选择** | `ckpt_name` / `vae_name` / `unet_name` / `clip_name`… | 跟素材分开摆，缺模型时标题变红 |

> 以前素材和模型混在一个「素材 / 模型」框里，选模型要在一堆图片里翻；LoRA 的名字在模型区、
> 强度被 `strength` 规则抓进参数区，5 个 LoRA 配 5 个强度全靠猜。现在都拆开了。

### 参数名全是中文

工作流里的 widget 名是英文（`seed` / `steps` / `strength_model`…），面板上一律摆中文：

- **提示词引导 (CFG)**、**随机种子**、**采样步数**、**噪声调度器**、**重绘幅度**、**强度（模型）**…
- 认得的整名直接对（`~180` 条对照表），不认得就按词根拼（`frame_load_cap` → 帧载入上限），
  实在认不出才留英文 —— 全库 25 个工作流的实测里已经没有漏网的英文名。
- 英文原名缩成右侧小灰字，回头对工作流时不用翻文档。
- 浮点尾巴擦干净：`0.7000000000000002` 显示成 `0.7`（只修显示，不动实际值）。

### 一采 / 二采：只看采样器在图里的先后

双采样工作流里「步数 / 种子 / 宽度 / 采样器」在两道上各有一份，名字完全一样。
分道规则很直接 —— **第一个采样器（含它自己）之前的节点算一采，第二个采样器（含它自己）
之前、且没被一采认领的算二采**，再往后依次类推：

- **两采共用的节点算一采**（模型链、文本编码、LoRA 主链都在这里）；
- **采样器下游**的解码 / 合成 / 保存节点，跟着它上游最后那个采样器走；
- **只有一道采样时不标**（单采样工作流不会平白多出一层「一采」标签）；
- **只数真跑采样的节点**：得产出 `LATENT` / 画面才算。名字里带 Sampler 但只出
  `MODEL` / `SAMPLER` / `SIGMAS` 的是「采样契约」——比如 `MiniMaxH3DualClockSamplerT8`、
  两采步数规划、两采细节混合。它们算进所在的那道（真实一采之前 → 一采），
  **不单独占一道**。h3长视频就是靠这条从三块收回两块：真采样只有 `PASS 1` / `PASS 2`。
- 音频分离器（`MelBandRoFormerSampler` 之类）同理不算采样器 —— 否则它会把分道整个带偏。

特例：导演台的「精修」（`MiniMaxH3DirectorRefine`）输出的是精修句柄（`MMX_DIR_REFINE`），
画面藏在里面，所以按「产出画面」算一道；它是挂在导演台的 `refine` 口上的，
图上排在导演台**前面**，照连线会被判成一采 —— 语义上它是第二采，所以这条边反着记。

实测：导演台 **一采 21 项 / 二采 6 项**、h3长视频 **一采 27 项 / 二采 19 项** 两块、
动作迁移与 K2-漫转真各两块；`H3双采样4步综合节点` 的第二采是旁路状态，所以只有一块。

额外还有一层：同一道里常常有好几个节点都叫「宽度 / 视频偏移」（导演台 + 偏移调节 + 分辨率），
所以**出现重名时**会在参数标签右边挂一个小角标写清是哪个节点的（`#2 VHS_VideoCombine`、
`偏移调节`…），不重名就不挂，保持干净的两列布局。标签前的小 `一采` / `二采` 角标是双保险：
单看一个输入框也知道改的是哪一道。

**参数一律连着排，不留半格空白**：以前按节点分块 —— 分辨率只有一个「总像素」、
每个 `VideoCombine` 只有一个「帧率」，这种单字段节点会自己占一行、右边空半格，
十来块凑起来就是一大片白（`h3长视频` 一采曾被切成 6 块）。现在的做法是：

- 每道次里所有参数排进**同一张两列网格**，节点名降级成标签右边的角标，归属照样看得清；
- 角标带序号且**序号在最前**（`#3 VHS_VideoCombine`）—— 角标窄的时候会被省略号截尾，
  序号在后面就跟着一起没了，五个「帧率」又变成一模一样；
- 前置行（画幅 / 分段模式 / 时长）**是单数时，把下面第一格提上来补满**，正好是「后面的参数往前移」；
- 网格**最后一格是单数时横跨两列**（`.grid2 > *:last-child:nth-child(odd)`），右下角不再留半格。

### ComfyUI 里改不了的参数：画布也不给改

有些节点在前端把一批 widget **藏起来**（`computeSize` 压成 0，由自己的面板顶替），
还有些值本来就是别的参数**算出来的**——画幅 + 总像素 → 宽高，尺寸模式 → 目标宽高。
这些在 ComfyUI 面板里根本点不到，画布以前却给了输入框：改了不生效，
还会让工作流里出现两个互相打架的值（宽高 864 vs 画幅 16:9 · 0.2MP），跑起来必然出错。

现在它们收进参数区底部一个折叠块 **「ComfyUI 里改不了的参数 (N)」**：
只显示值、不给控件，鼠标悬停写明是谁接管了它；**提交时也一律用工作流里的原值**，
旧存档里残留的覆盖值会被忽略。

覆盖到的情况：

| 节点 | 被锁的参数 | 谁接管 |
|---|---|---|
| `MiniMaxH3Director` | `width` `height` `total_frames` `frame_rate` `cfg` `global_prompt` `timeline_data` `ref_max_size` `export_*` | 时间线面板（**`task_type` 不再锁**：分段模式提到参数最前面，改它会同时写回时间线的 `global.taskType`） |
| `MiniMaxH3DirectorRefine` | `aspect_ratio` `width` `height` `target_width/height` `steps` `denoise` `sigmas` `schedule` `*_upscale_model` | 跟随导演台 / 精修面板 |
| `MiniMaxH3LearnedLatentUpscaleT8Advanced` | `target_width` `target_height` | 只在 `size_mode=target_dimensions` 时才解锁 |
| `MiniMaxH3DirectorSelfLift` / `SemanticBridge` / `Pack` | 同导演台那套 | 时间线面板 |

名单写在 `js/app.js` 的 `HIDDEN_WIDGETS` 里，按 `类名 → { 参数名: 原因 }` 组织；
新插件也有这毛病时，往表里加一条就行（派生类名以 `MiniMaxH3Director` 开头的会自动套用）。

> 被工作流 bypass 掉的 LoRA **也列出来**，只是卡是灰的、标着「已停用」——
> 以前它们整张卡都不显示，只能回 ComfyUI 里按 Ctrl+B 解旁路；现在在画布上点一下「启用」就行。
> 「LoRA 数量」= 活卡 + 停用卡。

### 素材槽：数量按工作流自己的上限

素材区不是「工作流里有几个 `LoadImage` 就摆几张」，而是按**这个工作流内置的素材上限**来：

- 上限从 ComfyUI 的 `/object_info` 里读 `COMFY_AUTOGROW_V3` 的 `max`，**不写死**。
  例如 h3（`MiniMaxH3AudioConditioningT8` / `MiniMaxH3Unified` 的 omni_reference）是
  **图 9 / 视频 3 / 音频 3**；换个工作流上限自动变。
- 右上角实时显示 **`图片 6/9 · 视频 0/3 · 音频 0/3`**。
- **一格一图、按钮在格下、同类型横排**：每个素材缩成一格——左上角标号（1、2、3…，连续编号不跳号），
  底下是文件下拉 + 「上传 / 停用」；停用的格底下多一行「未生效」。格子按类型分组排成网格、宽度自适应
  （节点 360px 默认宽 ≈ 3 列，拉到 600px ≈ 5 列），6 张参考图从「6 条整行」压成「2 行」。
- **从素材库直接拖进格子**：素材库里点住一个文件，拖到任意一格里松手 = 给这一格换文件。
  output 里的文件会自动复制一份进 `input/`（名字固定成 `xy_原名`，同一个素材反复拖只覆盖同一个文件，
  input 不会被灌满）；类型对不上会直接提示，不会硬塞。
- **有素材的槽才摆出来，空槽一律隐藏**：末尾一个 `＋ 参考图` 方框（跟素材格同宽），点一次露出一个空槽（下拉 / 上传随你）。
  池里还有工作流自带的空 `LoadImage`（值写成 `None` 那种）就先复用，用完了才由画布补一个新的加载节点。
- 工作流里被 **bypass** 的素材节点也会摆出来（标「未生效」+ 一个「启用」按钮）——
  这些图你一定是想用的，别让它们静默消失；点「启用」或直接改图，它就会被接回参考槽。
- **接了上游线的格子也有「启用」**：线在、可加载节点在 ComfyUI 里是旁路时，这一格照样会标
  「未生效」。以前这种格子一个按钮都不给（按钮只给「没接线」的格），只能回 ComfyUI 按 Ctrl+B；
  现在点「启用」就把那个节点从 mode 4 拉回 0，并同步写回文件。
- 每张卡右上角有 **「不启用」**：这次生成先不用它（`LoadImage` 连同指向它的参考槽一起
  从提交里摘掉），节点和文件都留在画布上，随时点 **「启用」** 开回来。
  **「不启用」同时会写回 ComfyUI 的工作流文件**（把那个节点设成 bypass），见下面「和 ComfyUI 同步」一节。
- 素材槽是**按槽号接回去**的：h3 长视频那种 LOW / HIGH 两套条件节点共用一个素材池，
  填一个槽会同时接给两个节点的同一个槽位。
- 空槽**不会**被提交：加到 9 个只填 3 个，跑的时候只发这 3 个 `LoadImage`，不会因为空路径 400。

### 和 ComfyUI 同步（双向）

画布读的、改的都是 ComfyUI 自己的 `<ComfyUI>/user/default/workflows/*.json`，所以两边必须对齐：

**ComfyUI → 画布（读）**

- 节点标题栏的 **⟳**：点一下重新读磁盘上的工作流文件，按最新内容重建节点
- ComfyUI 那边把文件存了（Ctrl+S / 自动保存），**20 秒内画布自己跟上**，不用点 ⟳：
  启停过哪个 LoRA、加了删了哪些节点、哪些参数变了，都会 toast 说一句
  （正在这个节点上打字时会先让一步，只亮黄点，不冲掉你手里的输入框）
- **刷新页面**就等于重读一遍：所有工作流节点都会按最新文件重建
  （以前这里会踩浏览器的启发式缓存，刷新也拿旧版 —— 现在这些请求一律 `no-store`）
- 重建时**画布上的东西不会丢**：参数、素材槽、启用/停用名单都保留；
  如果同一个参数你在画布和 ComfyUI 都改过，**以 ComfyUI 为准**（提示里会说改了几个）
- ComfyUI 里被 bypass 的 LoRA 不在提交里，画布上会补一张**灰卡**（标「已停用 · 这次生成不加载」），
  点它的「启用」就会把这个节点重建回提交里、把下游重新挂回它、并把文件里的 `mode` 改回 0

**画布 → ComfyUI（写）**

- 点素材卡 / LoRA 卡的 **「不启用」/「启用」**，会把这个节点的 `mode` 写回工作流文件
  （停用 = `mode 4` 紫旁路，跟手点 Ctrl+B 一样；启用 = `mode 0`），
  所以**从 ComfyUI 界面直接跑那个工作流也是同样的启停**，不会再「画布停了、ComfyUI 还在用」
- 写盘前先备份到 `user/default/xy-wxhb-backup/<工作流名>.<时间>.json`（每次会话每个工作流一份；
  同样写单行紧凑 JSON，跟被打回的那个文件排版一致，要回滚直接盖回去即可）
- 🔴 **写完会回读校验**：ComfyUI 那一页正开着这份工作流时，它迟早会把内存里那份存回去盖掉我们写的，
  这时 toast 会直接说「写回被挤掉了」并自动补写一次；还是不行就把问题挂在 **LoRA 段标题**上
- 🔴 **LoRA 段标题会亮「⇅ N 项没写回」**（橙黄色小按钮）：画布上点过的启停跟文件对不上时出现，
  点它就重推一次。平时那里显示的是「几个 LoRA」，不占地方
- 画布补出来的加载节点不在文件里，这种会提示「ComfyUI 文件里没有它」，不用管
- **画布上的每一格都会写回**：改参数、换模型、拖 LoRA 强度、
  换素材文件、在文本节点里改提示词，都会把这些值落进工作流文件，
  toast 说「已写回 ComfyUI：steps、cfg…」。以前只有启停和 LoRA 强度会写，
  步数、提示词这些只活在画布内存里 —— 从 ComfyUI 界面跑同一份工作流用的还是旧值，
  同一份工作流两个版本，跑出来自然对不上
- **不用敲回车**：数字框、文本框、提示词都是边打边记，**停手 3 秒自动写回**
  （一直打个不停时，从这一轮第一下算起最多 3 秒也会写一次）；
  下拉、勾选、换素材这类一次到位的控件 0.7 秒就写
- **点输入框以外的地方立刻写**（画布空白、另一个节点、别的格子都一样），
  切走窗口 / 切标签页也会立刻写，不用再按回车催它
- 写回**以磁盘那份为底**再改字段：ComfyUI 那页刚存的改动不会被画布内存里的旧版整份盖掉
- 写参数跟写启停是**同一套规矩**：先备份、写完回读校验（HTTP 200 不算成功），
  被 ComfyUI 那一页盖掉就补写一次，还不行就直说「没写回：文件里还是 X」
- 下拉值在文件里可能存成「值 — 中文说明」（`task_type` 就是这样），比较前会归一化，
  不会因为你改了别的参数就把它无谓地重写一遍
- 工作流文件里没有的格（画布补出来的加载节点、被内联的常量）**不会**硬写，
  宁可不动也不串到隔壁参数上

> ⚠️ 两处同时开同一个工作流会打架：**ComfyUI 网页里那份是内存态**，画布写回文件后，
> ComfyUI 那一页不会自己刷新 —— 要重新打开这个工作流才看得到旁路。
> 更麻烦的是它再保存一次就会把画布的改动盖回去（画布会在 20 秒内发现并亮「没写回」）。
> **推荐：改启停就在画布里改；画布上改完，在 ComfyUI 里重新打开那份工作流再看/再跑。**

> 不想让画布碰你的工作流文件？F12 里执行 `localStorage["xy-wxhb.pushmodes"]="0"` 再刷新，
> 之后就只读不写（`="1"` 或删掉这一项即恢复，默认是写）。

### 向前连线：从素材卡自己的端口往外拉

连带线入口都不在节点顶上了 —— **连线从「那一格」自己出发**，拉出来的一定落在这一格上：

1. 素材卡 / 提示词字段左边都有一个**虚线圈**（还能拉的格子才有）
2. 从虚线圈往外拖：
   - 松手在**空白处** → 就在松手的位置生成对应类型的素材节点（文本格就是文本节点），**并直接接上这一格**
   - 松手在**别的输出口**上 → 直接把那条线接到这一格
3. 已经接过线的格子，圈变成实心：再往外拖 = **换一个来源**（旧线自动换掉，原来的节点留在画布上）；
   只是点一下不拖，不会把已有的线弄丢

比「先建节点再拖线」少两步，也不会像以前那样接错格子（以前是从节点顶上的 `＋` 接第一个空闲口）。

> **线画在节点上面**：素材接到哪一格要一眼看得出来，被节点压住就只看见「有线」、看不出「接哪儿」。
> 线本身不吃鼠标（`pointer-events: none`），盖在节点上照样点得到、拖得动。
> 每根线还带一道**往目标方向跑的光**（光晕 + 亮芯两条叠着，`pathLength=100` 归一化，
> 线长线短都是同一节奏，相位随机错开不会一起闪）—— 一眼看出数据是往哪边流的。

### 输出内容节点

运行成功后，`syncOutputs()` 按产出类型挂节点：

- 有图 → 右侧生成「结果 · 图」；有视频 → 「结果 · 视频」；有 `text` → 「结果 · 文本」（带复制按钮）
- 一条 `key: null` 的线把工作流节点和它连起来（只表示「结果流向这里」，不对应任何字段）
- **重复跑不会越堆越多**：已有同类型的内容节点就原地更新（文件名、预览一起换）
- 内容节点有输出口，可以继续当上游：图/视频喂给下游的 `LoadImage`，文本喂给提示词字段

> 好处：一个工作流跑 20 次只留一个结果节点，画布不会被历史图撑爆；
> 想留档就把它拖开或另外复制节点。

### 手动把产出接进素材节点

工作流节点的输出口不光能接下游字段，还能**直接拖到素材节点上**，而且拖线时会**按产出类型精确分流**：

1. 从工作流节点的输出口（右边缘小圆点）**拖到素材节点的输入口**（左上角小圆点，和右上角的输出口同一水平线）→ 连成一条 `key: null` 的线
2. **拖线过程中只有匹配的素材节点会亮**：h3 是视频流，就只亮视频节点的输入口（图片/音频节点自动变暗）；krea2 是生图流，就只亮图片节点——和从输入口拉线时的分流反馈一模一样。判不了产出类型的工作流（标了 media）才万能试
3. **拖到空白处松手 → 弹出一个「能吃这种素材」的工作流清单**，挑一个就把素材接到它第一个空着的口上
   （图接图、视频接视频、文本接文本；文本自动避开 negative 那一格）；清单里一个都没有时，
   右下角「＋ 只建一个「图像输入」」还是老路——就地落一个素材节点并接上，节点顶部显示「等待「XX」的产出」；
   只是点一下口没拖（<6px）则什么都不会发生
4. 松手在变暗的口上会直接拒绝：「类型对不上：这里是「图像」输入」，不会连上再让你跑完才发现
5. 跑这个工作流后，产出会**优先写进连着的素材节点**——h3 出视频就自动在视频节点里播放，krea2 出图就自动在图片节点里显示（自己那份本地文件不动，被产出「顶替」）
6. 节点正文最顶上标「产出 · 来自「XX」」（紧挨着输入口）；想换回自己的本地文件，点一下「**改用本地文件**」就切回去
7. 万一连上了但跑出来对不上（比如工作流实际出了别的），会弹提示说清「XX 要图片、这次出来的是视频」，并照旧在右边补一个结果节点，不让你干等

> 素材节点因此多了一个**输入口**：空着时是纯素材（靠本地文件/上传），
> 被连上后优先吃上游产出，本地文件只是备胎，随时能切回。

### 往下游接：从素材拖出来直接挑工作流

素材（图像 / 视频 / 音频 / 文本，内容节点也算）往右下拖线、松手在空白处，**不再给你塞一个「素材节点」**
——素材接素材等于原地打转。现在弹的是一个清单：

1. 清单只列**真能接这种素材**的工作流：判定用的是「接线时同一套逻辑」（素材槽 + 可拉线字段 + 被停用的加载节点），
   所以列表里的点了必然接得上，不会出现「选了没反应」。**以入口为准**：参数里有 `duration` 但没有视频入口的流
   （`H3文生视频` / `H3图生视频`）不会列出来，列出来也是接不上的空节点。
   两类例外也算能吃：
   - **autogrow 口留着容量、但图里没摆加载节点的流**（h3 的参考视频口就是这种）—— 挑中时**先补一个空槽**再接；
   - **导演台**（`MiniMaxH3Director`）：源视频在时间线里、不在连线口上，**分段模式切到 v2v 才出现** ——
     它照样算能吃视频，接的时候画布会把分段模式**自动切到 v2v**，并把文件名 + 帧数写进 `timeline_data`
2. 每一行右边的 `图 / 视 / 音 / 文` 是这个工作流能吃哪几种，**当前这种是高亮**的
3. 挑中 → 工作流节点**落在松手的位置**，素材自动接到它**第一个空着的口**上：
   - 图像槽接图像、视频槽接视频；文本优先接 `prompt / positive` 这类正向提示词，**避开 negative**
   - 空着的 `ref_images.N` 会**显式写进采样节点**（不然光有条线，采样节点不知道用第几个槽）
   - 工作流里那个加载节点如果是被停用（bypass / mute）的，会**顺手救活**——不然接上去等于没接
   - 接**导演台**时：先切模式（t2v → v2v），再按源视频的真实帧数/帧率/宽高重写时间线
     （`totalFrames` / `frameRate` / `video.fileName`），旧的片段、关键帧一起清掉（对不上新片子的长度，留着必报错）；
     节点「素材」一格会显示「来自「XX」」，点它可断开
4. 搜索框边打边筛，`↑↓` 选、`Enter` 接上、`Esc` 或点画布外面取消（取消就什么都不建）
5. 兜底：清单右下角「**＋ 只建一个「图像输入」**」是以前的老路，想要一个空素材节点时点它

> 识别结果有缓存：第一次拖线会扫一遍工作流的输入口（本机 ~80ms，边扫边显示进度），
> 之后直接用缓存；侧栏工作流列表点 ⟳ 重扫时会一起清掉。

### 素材库（直连 ComfyUI 的 input / output）

侧栏顶部两个页签：**工作流** / **素材库**。

- **input 素材 / output 结果** 一键切；按**一级子目录分「子库 / 项目」**（`output/图片`、`output/video`、`input/xxx`…），后面跟文件数
- 缩略图网格：图片显示缩略图、视频显示首帧、音频显示 🎵；左上角是文件大小，右下角悬停出现 **改 / ✕**
- **改**：就地重命名（`POST /api/lib/rename`）。点开后文件名那一条变成输入框，**扩展名拆成固定的灰色后缀**、不让改 ——
  库里靠后缀区分图片 / 视频 / 音频，缩略图也靠它决定怎么画，手一滑把 `.png` 写成 `.jpg` 就全乱了。
  回车 / 点别处 = 提交，Esc = 放弃；只改主干名，后端会把扩展名拼回去（前后空格自动去掉）。
  重名会直接拦下来（不会覆盖已有文件），非法字符（`\ / : * ? " < > |`）、Windows 保留名（`CON`、`COM1`…）、
  以点或空格结尾一律拒绝，失败时停在编辑态、名字还能接着改。只改大小写也算改（走一次临时名中转）。
  改完提一句「画布里引用旧名的要重选」—— ComfyUI 节点里存的是文件名，旧名就对不上了
- **拖到画布**：变成内容节点直接可用（文件已经在磁盘上，不用重传）
- **拖到素材格上**：直接给那一格换上这个文件（工作流的素材格、图像输入节点都收），见「素材槽」一节
- **⤴ 上传**：把本机文件传进当前子库（`input/<子库>/`），支持多选
- **＋ 新建子库**：在 input 或 output 下建一个一级目录（按项目命名）
- **☑ 批量删除**：每张卡右上角一个勾选框 → 勾几张文几个，顶上那条 **全选 / 反选 / 删除 / 取消**
  会亮起来（「已选 N 个」实时更新）。删除前弹确认框，把要删的文件名都列出来
- **✕ 删除单个**：真删磁盘文件（弹确认框）。⚠️ 如果这个文件正被某个节点引用，那个节点会变成「素材缺失」，重新选一个即可
- **删整个子库**：子库按钮右边那个小 **✕** → 一次性删掉这个文件夹（含里面所有子目录），
  确认框会写清 `input/<子库>` 和大概多少个文件。**根目录不给这个口**，也不会被删
- **删子库内部的文件夹**：文件列表顶部有一排「文件夹」chip（从文件路径反推出多级目录，如 `图片/Qwen2.1/2026-10-08`），
  每个后面都有 **✕** → 连文件夹带内容一起删。侧栏的 ✕ 管一级子库，这排 chip 管子库内部的多级目录

### 成品库：把满意的产出单独收出来

`output/` 是全输出库——跑多少次都在里面，废稿成品混在一块。**成品库**就是 `output/成品库/`，
专门放挑出来的：

- 素材节点接住产出后，按钮行有一个 **⭐ 存到成品库**（结果节点上也有）→ 复制进去，**源文件不动**
- 同名不覆盖：库里已有同名文件就自动加 `_1`、`_2` 后缀，绝不盖掉已收的
- 存过的按钮变成绿色的 **已存 ✓**，悬停显示收进去的文件名；再点一次会另存一份
- 「已存」状态跟着画布存档走，刷新后还认得
- 收完在素材库面板切到 **output 结果**，就能看到「成品库」子库（带文件数），
  里面的图可以直接拖到画布复用

> 为什么这块也要后端：ComfyUI HTTP 接口没有「复制文件」，`POST /api/lib/collect` 由 serve.py 做，
> 只读源（`input/` `output/` `temp/` 都行）、只写 `output/成品库/`，路径全部过越界校验。

> 为什么这块需要后端：ComfyUI 官方 HTTP 接口只有 `/view`（按文件名取文件），
> **没有「列目录」和「删文件」**。所以 `serve.py` 直接读本机 `input/` `output/` 目录提供这些能力：
> `GET /api/lib/root|projects|items`、`POST /api/lib/project|delete|collect|rename`、`DELETE /api/lib/file|project|dir`。
> 它会自动探测 ComfyUI 根目录（`comfy-root.txt` → 环境变量 `XY_WXHB_COMFY_ROOT` → 常见路径），
> 探不到就在面板里让你手填一次，记在 `comfy-root.txt` 里。所有路径都过越界校验，只动 `input/` `output/` 里面。

### 四种素材节点

侧栏顶部「新建素材节点」四个按钮，或者直接把文件拖到画布上（会按扩展名自动判断类型）：

| 节点 | 干什么 | 输出口颜色 |
|---|---|---|
| **文本输入** | 一个多行文本框，拖给工作流的提示词字段 | 蓝 |
| **图像输入** | 选/拖一张图，传进 ComfyUI 的 `input/` | 绿 |
| **视频输入** | 选/拖一个视频（mp4 / webm / mov…） | 紫 |
| **音频输入** | 选/拖一个音频（mp3 / wav / flac…） | 橙 |

文本节点可以直接改字，右边的圆点可以同时拖给多个工作流的多个提示词字段（一个输出接多条线）。

### 把节点串起来（拖线）

每个节点**右边缘那个小圆点**是输出口，下游节点**输入字段左边的圆点**是输入口。

- 从上游输出口**按住往左拖**，拖到下游输入口上松手 → 连成一条贝塞尔线
- 拖的时候只有**类型对得上**的输入口会亮，对不上的变暗；松错地方会提示类型不符
- 连上之后那个输入框变成蓝色的「来自「XXX」」，点一下就能断开
- 再点下游的 **▶**：上游没跑过会**先自动跑上游**，跑完把产物交给下游，最后才提交
- 提交之后这枚 **▶** 就地变成红色的 **■**（同一个按钮、同一个位置）—— 点它就是**停止**：
  还在排队没开始的先把队列撤掉，正在跑的走 `/api/interrupt` 中断（带 `prompt_id`，不会误伤
  ComfyUI 里别的任务）；画布上状态变「已停止」，**不算报错**，也不会弹一片红

连线支持四种数据类型：

| 上游 | 能接的下游字段 |
|---|---|
| 文本节点 | 名字像提示词的字符串字段（`prompt` / `text` / `positive` / `negative_prompt` / `value`…） |
| 图像节点、工作流节点 | `LoadImage.image` |
| 视频节点、工作流节点 | `VHS_LoadVideo.video`、`CS_Load_Video.video`、`LoadVideo.file` |
| 音频节点、工作流节点 | `LoadAudio.audio`、`VHS_LoadAudioUpload.audio` |

> 工作流节点的产出类型运行时才确定，所以它的输出口是灰的「万能口」，
> 图片 / 视频 输入都能接，运行时会挑对应的那份产出。

- 上游产物如果是 `output/` 或 `temp/` 里的文件，会先下载再重传进 `input/`，
  文件名固定叫 `xy_<上游id>_<下游id>.<ext>`，重复跑只覆盖同一个文件，不会把 `input/` 灌满

### 改节点大小

每个节点**右下角有个斜纹小把手**（鼠标移上去变亮）：

- 按住它拖动 → 宽高自由改，最小 200 × 84；高度不够时**内容区自己出滚动条**，
  标题栏和运行状态始终留在原位
- **双击把手** → 恢复「宽度按类型默认、高度跟着内容走」
- 拖出来的尺寸会**存进画布**，刷新、导出、导入、复制粘贴都带着走
- 缩小后在内容区滚到底，端口滚出可视区的那根线会**自动隐藏**，不会飘到节点外面
- 内容区滚到顶 / 到底就**停住**：不会顺势把画布放大（以前滚到底再滚一下整个画面就缩了，
  手一滑就找不到刚才在看哪儿）。缩放只在**节点外的空白画布**上响应；
  确实想在节点上缩放，按住 `Ctrl` / `⌘` 再滚

> 运行状态（「运行中… 45%」「完成 · 1.1s」「已停止」「报错信息」）挂在**节点头部**、
> 标题右边——工作流节点动辄四五百像素高，状态在底部得翻下去看，现在第一眼可见；
> 文案太长会省略显示，鼠标悬停看全文。

> 高度自动（没拖过）时不会出滚动条，节点还是原来那样「有多长画多长」，
> 只有你亲手拉过高度才会切成固定高 + 滚动。

### 批量选择 / 批量复制 / 批量删除

**按住空格 + 左键拖一个框**（从空白处或节点上起手都行）：

- 框碰到的节点**全部选中**，框选期间底部浮出一条操作栏
- 框的中途按住 `Shift` → 在已有选中上**加选**
- 空格按着时，拖端口、拖标题栏都会让位给框选（不会误拉线、误移动）
- **拖任意一个选中节点的标题栏** → 整组一起移动

底部操作栏：`已选 N 个` · 复制 · 再来一份 · 删除 · 取消

| 快捷键 | 作用 |
|---|---|
| `Ctrl+C` / `Ctrl+V` | 复制选中节点 → 粘贴（往右下错开 48px，连按几次依次错开） |
| `Ctrl+D` | 原地再来一份（复制 + 粘贴一步到位） |
| `Ctrl+A` | 全选画布上的节点 |
| `Delete` / `Backspace` | 删除所有选中的节点 |
| `Esc` | 取消选中 |

复制的是**纯数据**：工作流节点会重新问 ComfyUI 拿一次定义，但参数、素材槽、
启用/停用状态、节点尺寸全都带过去；**选中节点之间的连线**一起复制，
连到外面去的线不复制。

### 画布背景：日间 / 自定义图片

右上角（「适配」旁边）两个按钮：

- **☀️ 日间**：整个界面翻成浅色（顶栏、侧栏、节点、弹窗、连线、画布网格一起变）。
  再点一次回到默认的深色。选择会记住，刷新页面不用重设
- **🖼 背景**：选一张本机图片当画布背景（铺满、居中裁切，节点和线照常盖在它上面）。
  大图会自动缩到长边 1920 再存；**缩放后仍超 5MB 会拒绝设置**（ toast 说清楚）。
  图片存在浏览器的 **IndexedDB** 里——localStorage 一共才 5MB 左右，
  一张高清背景图就能把配额爆掉（连画布存档都会写不进去），所以不能图省事存那儿。
  **已经设置了再点一次** → 确认后清除，回到网格底色

两个都是界面级设置，存在本机浏览器里（localStorage），不进画布 JSON 存档——
换电脑/清浏览器数据后需要重设，画布存档本身不受影响。

| 操作 | 方式 |
|---|---|
| 折叠 / 展开侧栏 | 顶栏最左边的 `«` ／ `Ctrl+B` |

## 它是怎么工作的

```
浏览器 ⇄ ComfyUI HTTP API
         /api/userdata     列出并读取 workflows 目录下的工作流
         /object_info      5556 个节点的输入定义
         /api/prompt       提交任务
         /history/{id}     轮询结果
         /view             取回图片/视频
         /upload/image     上传素材到 input/

浏览器 ⇄ serve.py（同源，127.0.0.1:8277）
         /api/lib/root                     ComfyUI 根目录探测 / 手动指定
         /api/lib/projects?kind=input      按一级子目录列子库
         /api/lib/items?kind=&project=     列子库里的文件（递归，mtime 倒序）
         /api/lib/project                  新建子库
         /api/lib/rename                   改文件名（扩展名不动）
         /api/lib/file                     DELETE 删文件
         /api/lib/project                  DELETE 删整个一级子库
         /api/lib/dir                      DELETE 删子库内部多级文件夹
```

核心难点是 **UI 工作流 → API prompt 转换**，实现在 `js/convert.js`：

- widget 值与连线分别映射，`widgets_values_named` 优先于数组（避免下标串位）
- 连接型输入按 `links` 表还原成 `[节点id, 槽位]`
- `Reroute` 透传、`SetNode/GetNode` 变量、`Primitive*` 常量节点全部解析
- **bypass（mode=4）做输入→输出透传**：被禁用的节点不会被提交，但下游能正确接到上游
- COMBO 值归一化：ComfyUI 存的「Ref2VA — 参考生音视频」会还原成纯值 `Ref2VA`
- 认不出的节点/断链如实记录成告警，不产半截 prompt

### 实测覆盖面（本机 25 个工作流）

- **13 个**直接通过 ComfyUI 自己的校验
- **7 个**因本机缺素材被拦（模型/图片/视频文件不在）—— 面板里会标红让你重选
- **5 个**缺插件节点或用了子图（subgraph 暂不支持）

参数面板另跑过一遍全量渲染：25 个工作流全部画出「素材 / 参数 / LoRA / 模型」四段，
页面零报错，**没有一个参数名还是英文**。一采二采的分道结果：导演台 2 块、h3长视频 3 块、
动作迁移 3 块、K2漫转真 3 块；单采样的（H3图生视频 / 动漫PV / 70-Qwen…）**保持一整块不标道次**。

改完「参数连续排布」后又全量跑了一遍 28 个流：**没有空网格**，参数格数不变
（h3长视频 130 格 / 动作迁移 136 格 / 多人白模 105 格），网格数从「一节点一张」降到 1–3 张
（h3长视频 3 张 `[6,13,10]`、h3-2采五段 2 张 `[6,10]`、qwen2.1局部编辑 1 张 `[15]`）。
这三个流已逐张截图确认：右下角不再有半格空白。
唯一失败的 `SAM3DB-rigged_mesh_manipulation.json` 是本机没装 SAM3D 节点，与面板无关。

## 已知限制

- **子图（subgraph）不支持**：含子图的工作流会被跳过并告警
- **连线只覆盖「素材类」输入**：文本 / 图片 / 视频 / 音频。潜空间（`LATENT`）、
  `MODEL`、`VAE`、`CONTROL_NET` 这类模型级连接还不能拉线
- **素材库依赖本机目录**：只能管本机 ComfyUI 的 `input/` `output/`。连远程 ComfyUI 时
  `/view` 还能看图，但列目录/删除会失败（面板里会提示 ComfyUI 根目录没找到）
- **删除是真删**：素材库里的 ✕ / 批量删除 / 删子库都会直接删磁盘文件（`os.remove` / `shutil.rmtree`），
  不进回收站；删子库只允许一级子目录，根目录删不了
- **临时产出**：`PreviewImage` 这种 `type=temp` 的结果会被 ComfyUI 清理掉，
  内容节点状态里会标「临时（会被 ComfyUI 清理，建议另存）」
- 一个子库最多列 **400** 个文件（按修改时间倒序），太大的目录请分子库
- 连线传图会在 `ComfyUI/input/` 下留 `xy_*.ext`；一个画布 + 一条线对应一个文件，
  删节点不会自动删文件（去素材库的 input 里删即可）
- 素材节点上传的文件保留原文件名，同名会被**覆盖**（`overwrite=true`）
- **素材槽只对有 `COMFY_AUTOGROW_V3` 的节点生效**：像 `MiniMaxH3ImageToVideo` 只有
  `first_frame` / `last_frame` 两个固定口，就还是照旧摆几张卡，没有「上限」这回事。
  `max=0` 的 autogrow（Qwen 的 `images` 组）按「没有上限约束」处理，也不出槽
- **素材槽补的加载节点**：图 = `LoadImage`、视频 = `LoadVideoUI`（输出 IMAGE 帧批次，
  正好对上 h3 的 `ref_videos`）、音频 = `LoadAudio`。这三类本机缺了就会提示、加不了槽
- **框选按「碰到就算」判定**：矩形和节点外框有交叠就选中，不要求整个包住
- **固定高度 + 滚动的节点**：滚出可视区的端口不画连线（线会藏起来，滚回来就出现）；
  折在滚动区外面的输入口也一样拖不到，滚到它再拖
- **`MiniMaxH3Unified` 的 `media_state`**：这个节点还带一个 JSON 状态串（`image_count` 等），
  画布只改 `mode.ref_*` 的连线、不动这个串。实测提交能过，但节点内部要不要靠它重建面板未验证
- **画布上能改的都会写回**：点素材卡 / LoRA 卡的「不启用 / 启用」写回节点的 `mode`；
  参数格（步数、CFG、采样器、调度器、种子、宽高、LoRA 强度与模型、模型下拉……）、
  素材槽换的图 / 视频 / 音频文件名、文本节点里敲的提示词，**全都写回工作流文件**。
  打字类停手 3 秒落盘、点别处立刻落盘；拖着 spinner 改数不会每一下都写文件。
  停用 LoRA 的做法是「提交前把它从图里摘掉、下游接回它自己的上游」——
  直接删线会让 MODEL / CLIP 口缺输入，ComfyUI 只会回一句 Required input is missing。
  > 写回用的是**单行紧凑 JSON**，跟 ComfyUI 自己存的排版一致（同一个文件两边交替保存
  > 不会再在 ~84 KB ↔ ~144 KB 之间来回跳）。实测往返后与原文件逐字节相同，重复写幂等
- **双向同步不是实时协同**：ComfyUI 网页里那份是内存态，没按 Ctrl+S 就还是旧文件；
  画布写回磁盘后，ComfyUI 那边**不会自己刷新**（要重新打开那个工作流才看得到旁路），
  而且它再保存一次就会把画布的改动盖掉 —— 画布会在 20 秒内发现、把启停状态标成
  「⇅ N 项没写回」，点一下重推即可。所以别在两处同时改同一份工作流
- **写回要回读校验**：写盘是一次 POST，返回 200 不等于落盘成功（ComfyUI 可能紧接着覆盖）。
  每次写完都按时间戳再 GET 一遍比对 `mode`，不一致就补写一次，还不一致就直接报错，不谎报「已写回」
- **「改不了」的名单是手写的**：`HIDDEN_WIDGETS` 覆盖的是本机这几个 H3 / 导演台系列的节点。
  别的插件如果也把自己的 widget 藏起来（前端 `computeSize` 压成 0），画布识别不出来，
  还是会给输入框 —— 遇到就往表里加一条
- **画布补出来的加载节点写不回**：`xy_*` 这种临时加的 `LoadImage` 不在工作流文件里，
  停用/启用时只能作用于本次提交（toast 会提示「ComfyUI 文件里没有它」）
